## How to Run the Lab

1. Open `barclays_hol_data_product.html` in your browser
2. Follow the steps in order — each step has inline SQL you can copy directly into Snowsight
3. Companion `.sql` files in the `sql/` folder contain the same code for offline reference
4. The `dbt/` folder contains the models generated by Cortex Code in Step 3

## Step 3: Cortex Code + dbt

Step 3 uses **Cortex Code** (Snowflake's built-in AI coding assistant) to generate and deploy the dbt project. You will paste a single prompt into Cortex Code and it will:
- Scaffold the full dbt project
- Generate staging and mart models
- Configure Snowflake connection
- Run `dbt run` and `dbt test`

The `dbt/` folder contains the expected output for reference.
